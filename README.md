# Disney+ Picture-in-Picture Fix

Chrome extension that adds back Picture-in-Picture on Disney+.

## Install

1. Download this repo (Code → Download ZIP) and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder.

## Use

Play a video on Disney+ and press **Alt+P** to open or close Picture-in-Picture.

Switch the toggle off to close PiP and turn the fix off.
